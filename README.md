# shinokami.dev

Personal portfolio built with [Astro](https://astro.build).

## Development

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # static output in dist/
pnpm preview
```

## Content

All texts, experience, projects, education and links live in `src/data/site.ts`.
